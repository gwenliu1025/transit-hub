# TransitHub v0.1.16

- 经营表现改为北京时间自然周期：本周从周一零点开始，本月从 1 日零点开始，均统计至今；图表与周期总额采用相同口径。
- 修复 31 天月份截掉月初、浏览器时区导致日期标签偏移及跨业务日旧缓存被当作今日恢复的问题；月初仍保留昨日对比。
- 历史快照查询使用既有北京时间业务日，不再依赖数据库会话时区；不变更数据库结构或历史记录。
- 仓库部署说明、默认 Compose 和界面版本链接统一指向此 Fork。默认从当前源码构建，不再拉取上游旧镜像；排行榜的滚动周期保持不变。

## 部署

按仓库 README 从源码构建并部署；已有部署先备份配置、数据库、Redis 和附件，再只重建应用，保留旧镜像用于回滚。

本 Release 同时提供 Linux amd64 镜像归档及 `SHA256SUMS`。校验后用 `docker load` 导入，镜像名为 `transit-hub:v0.1.16`；其它架构按 README 从源码构建。镜像来源与源提交记录在 `org.opencontainers.image.*` 标签中。

发布工作流要求前端日期回归、前端构建、后端 race/静态检查/构建、真实 PostgreSQL 集成及部署入口一致性验证全部通过，才创建本 Release。
