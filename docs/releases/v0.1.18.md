# TransitHub v0.1.18

本版恢复已有历史成本与净利润的正常展示，不重算或修改历史金额。

## 仪表盘

- 历史成本和净利润直接采用已有记录，不再因日结完整性标志缺失或未完成而隐藏。
- 昨日对比、自然周/月图表与总额、利润率和续航继续通过同一投影展示；保留零成本和负净利润。
- 真正缺少记录或数值无效时仍保留缺口，不补零、不推算，也不添加待核验标签。
- 已有营收、余额、北京时间边界及后端日结写入保护保持不变。

## 升级

无需历史数据回填或新的数据库迁移。先备份并在隔离副本预演，再仅切换应用；不运行历史营收回填命令，不覆盖数据库、Redis 或附件。

本 Release 提供 Linux amd64 镜像归档及 `SHA256SUMS`。核验正式来源与校验和后导入 `transit-hub:v0.1.18`。回滚仅使用保留的旧应用镜像，不恢复旧数据库。
